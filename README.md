# Malta VAT Solutions

I need to build a small business website to start offering my services as a VAT system auditor in Malta. In Malta, you need to apply for an EXO number by obtaining a VAT certificate from an independent auditor. I need the website to be professional and modern and it is important that it will be mobile friendly.

This project was built with [Lovable](https://lovable.dev).
